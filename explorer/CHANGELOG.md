# Changelog

## v0.2
- Tibia cartridge redesigned to load from the top, with looser bearing tolerances. The tight fit crushed the bearing's outer shell and made the linear guide rods bind.
- Shank: slightly looser fit for easier rod insertion.
- New part: bearing spacer (2 per leg, PETG like the tibia cartridge).
- Reprint the tibia cartridge, shank and bearing spacers if upgrading from v0.1.
